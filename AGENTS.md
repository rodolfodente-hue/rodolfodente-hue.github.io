- Do not add email addresses, account names, machine details, secrets, or anything else private. This includes this file and `PROJECT_RESUME.md`.

- Source material for portfolio pages comes from the private work-samples project (its page builder and mock live there). Its PC folder is listed in the shared agent rules. Never copy its files into this repo by hand.
- `job-bot/` and `pc-guardian/` hold the home pages and privacy policies that Google's app settings link to. Keep those addresses working and keep the text true to what each tool does.
